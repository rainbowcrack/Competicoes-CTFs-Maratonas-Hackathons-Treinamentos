### 📚 Entendendo os Diretórios

* **`Books/`**: Contém livros e PDFs teóricos sobre algoritmos e ciência da computação.
* **`Cursos/`**: Materiais de apoio, slides e exercícios práticos de cursos e oficinas (ex: Escola de Primavera da SBC, Oficinas de Programação da PUC).
* **`Judge/`**: Resoluções de problemas divididas por plataformas de juízes online (Beecrowd, Codeforces, LeetCode, Vjudge).
* **`Maratonas/`**: Códigos fonte e enunciados de provas de diversas competições (Maratona SBC, SBC Mineira, Maratona Feminina de Programação, OBI).
* **`Materiais/`**: ⚠️ **Atenção:** Os materiais desta pasta são **folhas que podem ser usadas para impressão**! São resumos, templates e *cheat sheets* (folhas de consulta) contendo algoritmos prontos e dicas de estruturas de dados para você imprimir e levar no dia da sua competição.

## 🚀 Como usar este repositório

1. **Faça o clone:**
   ```bash
   git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
   ```
2. **Navegue pelas resoluções:** Use as pastas de `Judge/` ou `Maratonas/` para encontrar o código referente a um problema específico.
3. **Compilando os códigos (exemplo em C++):**
   ```bash
   g++ -O2 -Wall arquivo.cpp -o programa
   ./programa
   ```
4. **Materiais para Provas:** Acesse a pasta `Materiais/`, escolha as folhas de consulta desejadas, faça a impressão (preferencialmente convertendo o markdown para PDF primeiro) e bons estudos!
